# เว็บไซต์แผนกลูกหีบ (Milling Section) – KBS Sugar สาขาสีคิ้ว

**เวอร์ชันเผยแพร่สาธารณะ:** ตัดเบอร์โทรศัพท์ส่วนตัวของพนักงานออกทั้งหมด (รวมถึงในโค้ดของหน้าเว็บ) คงไว้เฉพาะชื่อ ตำแหน่ง และกลุ่มงาน

เว็บไซต์แบบ Static พร้อมอัปโหลดขึ้น GitHub Pages ไม่ต้องติดตั้งโปรแกรมเพิ่ม

## วิธีอัปโหลดขึ้น GitHub Pages

1. สร้าง Repository ใหม่บน github.com แบบ **Public** เช่น `milling-sikhio`
2. กด **Add file › Upload files** แล้วลาก **ไฟล์ทั้งหมดในโฟลเดอร์นี้** (รวมโฟลเดอร์ `assets`) เข้าไป
   – `index.html` ต้องอยู่ชั้นนอกสุดของ Repository ไม่อยู่ในโฟลเดอร์ย่อย
3. กด **Commit changes**
4. ไปที่ **Settings › Pages** → Source: **Deploy from a branch** → Branch: **main** / **(root)** → **Save**
5. รอ 1–2 นาที เว็บจะอยู่ที่ `https://<ชื่อผู้ใช้>.github.io/milling-sikhio/`

## หมายเหตุ

- เว็บบน GitHub Pages (บัญชีฟรี) เป็น **สาธารณะ** – เวอร์ชันนี้ไม่มีเบอร์โทรส่วนตัวแล้ว แต่ยังมีชื่อพนักงาน ควรขออนุญาตก่อนเผยแพร่
- ข้อมูลจริงจาก Google Sheets: ประชาสัมพันธ์ · แผน PM · งานตรวจสอบ HSE · Safety sharing · อะไหล่สำรอง – ตั้งค่าตาม `google-apps-script/SETUP.md`
- ปุ่ม **เข้าสู่ระบบ** มุมขวาบน – ล็อกอินครั้งเดียว เพิ่ม/แก้ไข/ลบ ได้ทุกหน้า (ผู้แก้ไขสูงสุด 20 คน)
- รูปในการ์ดแสดงเต็มภาพ คลิกเพื่อดูขนาดใหญ่ / เลื่อนดูหลายรูป
- รองรับมือถือและติดตั้งเป็นแอปได้
- **ต้องอัปโหลดไฟล์ทั้งหมด รวม auth.js, lightbox.js, mobile.js, manifest.webmanifest และไอคอน**
- ข้อความในวงเล็บเหลี่ยม เช่น `[วันที่]`, `[จำนวน]` คือช่องว่างให้เติมข้อมูลจริง
- เปิดดูในเครื่องได้ทันทีโดยดับเบิลคลิก `index.html`
